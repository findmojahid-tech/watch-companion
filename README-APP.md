# Watch Companion

Android V1 for using a compatible Bluetooth call-audio watch as the mic/speaker for a cute task companion.

## V1 features
- Bluetooth communication-device detection and selection
- Watch speaker test
- Push-to-talk speech recognition
- Cute animated face states
- Add / list pending / mark done / reopen tasks

## Build
GitHub Actions builds a debug APK automatically. Open the latest successful **Build Android APK** workflow run and download the `WatchCompanion-debug-apk` artifact.

## Install
Unzip the artifact on your Android phone, open `app-debug.apk`, allow installation from the app you used to open it, then grant Microphone and Nearby devices permissions.

No root, bootloader unlock, custom ROM, or watch firmware modification is required.
